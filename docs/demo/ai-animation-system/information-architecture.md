# AI动画制作系统 信息架构

## 一句话定位

`AI动画制作系统` 是 `gemshin_nb` 模块中心下的一条完整业务系统，继承平台壳层与公共能力，在系统层组织项目、在项目层推进章节与分镜、在镜头层完成精修与生成。

## 层级树

```text
gemshin_nb
└── 模块中心
    └── AI动画制作系统
        ├── 系统首页
        │   ├── 项目中心
        │   ├── 全局素材
        │   └── 全局任务
        └── 项目
            └── 海港追光（示例）
                ├── 项目总览 / 项目工作台
                ├── 章节 / 分镜
                │   └── 镜头 27（精修层）
                ├── 项目素材
                ├── 项目任务
                └── 导出
```

## 导航分层

### 平台导航

由 `shell.vue` 提供：

- 首页
- 模块中心
- AI 助手
- 个人中心
- 账户与权限

### 系统导航

进入 `AI动画制作系统` 后出现：

- 系统首页
- 全局素材
- 全局任务
- 系统设置

系统导航只处理整个动画业务系统的公共对象，不直接代表某个项目。

### 项目导航

进入某个项目后出现：

- 项目总览
- 章节分镜
- 项目素材
- 项目任务
- 导出

项目导航只处理当前项目，不与系统级对象混用。

### 镜头上下文

进入单镜头精修层后，不再增加新的“一级导航”，而通过：

- 面包屑
- 当前章节 / 当前分镜列表
- 上一镜头 / 下一镜头
- 镜头任务面板

来表达用户所处的镜头上下文。

## 页面清单与作用域

### `module-center-entry-demo.html`

- 作用域：平台层中的模块发现入口
- 解决的问题：用户如何从 `gemshin_nb` 发现 `AI动画制作系统`
- 关键对象：模块卡片、系统定位、最近活跃度

### `system-home-demo.html`

- 作用域：业务系统层
- 解决的问题：用户如何在系统层看到项目中心、全局素材与全局任务
- 关键对象：最近项目、系统级队列、公共资产、进入项目动作

### `project-workbench-demo.html`

- 作用域：项目层
- 解决的问题：用户如何围绕某个项目推进章节、分镜和项目状态
- 关键对象：项目元信息、章节树、分镜面板、项目素材、项目任务、导出阻塞

### `shot-refine-demo.html`

- 作用域：镜头层
- 解决的问题：用户如何围绕单镜头做精修、替换素材、重跑任务和校验结果
- 关键对象：镜头画面、生成参数、镜头素材、镜头任务、版本对比

## 素材与任务归属决策

### 全局素材

- 归属：系统层
- 含义：可被多个项目复用的角色库、场景模板、声音资产、参考库
- 入口：系统导航 `全局素材`

### 项目素材

- 归属：项目层
- 含义：当前项目已经挂接或待补齐的素材实例
- 入口：项目导航 `项目素材`

### 全局任务

- 归属：系统层
- 含义：跨项目的排队、失败、导出批次和公共资源处理任务
- 入口：系统导航 `全局任务`

### 项目任务

- 归属：项目层
- 含义：当前项目的剧情整理、分镜生成、项目导出和项目内失败队列
- 入口：项目导航 `项目任务`

### 镜头任务

- 归属：镜头层
- 含义：当前镜头的图片生成、视频生成、配音、重试和版本校验
- 入口：镜头右侧任务面板

## 用户主路径

1. 从 `gemshin_nb / 模块中心` 进入 `AI动画制作系统`
2. 在系统首页判断是进入最近项目，还是先处理全局素材 / 全局任务
3. 进入具体项目后，在项目工作台切换章节和分镜
4. 进入单镜头精修层，围绕当前镜头做生成、替换、重试和校验
5. 处理完成后回到项目层继续推进，再回系统层看全局进度

## “字字动画”结构映射

| 字字动画结构 | 本次映射 |
| --- | --- |
| 创作空间 | 下沉为 `系统首页` 中的项目中心区，不再作为固定一级导航词 |
| 当前作品 | 收敛为进入具体项目后的 `项目工作台`，不再作为系统级固定导航 |
| 精修编辑页 | 映射为 `shot-refine-demo.html`，成为镜头层 |
| 素材库 | 拆成 `全局素材` 与 `项目素材` 两级 |
| 任务记录 | 拆成 `全局任务`、`项目任务`、`镜头任务` 三层 |
| 软件设置 | 归入系统导航的 `系统设置`，本轮不单独出页 |
